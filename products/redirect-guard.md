# Redirect Map Checker — Loops, Chains and Migration Coverage

Check a planned redirect map for duplicate sources, chains, loops and gaps in a supplied traffic inventory before deployment.

## The job

Regole duplicate, catene e URL dimenticati possono compromettere una migrazione.

## Start with a synthetic example

1. Open the [input example](../examples/redirect-guard-input.json). These are invented test records, never customer data.
2. Read the [computed report](../examples/redirect-guard-report.json). It was generated by engine 1.0.0 with an explicit evaluation timestamp.
3. For a licensed installation, load the same fields into the browser app or call MCP tool `redirect_guard`.

## Required input

- Table a: `from, to`
- Table b: `url, visits`

CSV accepts comma, semicolon or tab separators. Use decimal points; keep currency explicit. Maximum 5,000 rows per table and 2 MB per file (MCP: 2 MB total request). Dates need a timezone. Missing or ambiguous data is rejected instead of silently guessed.

## Output and review

Structured report, row-level findings, priority actions, formula-safe CSV and an input/result fingerprint through MCP. The local browser edition also exports HTML. Inspect review flags before changing your operational system.

## Boundaries

Static plan analysis. Does not crawl HTTP endpoints or promise search rankings.

## Availability

The functional browser/CLI edition is built and internally tested. The hosted paid service is being qualified; this repository is a public technical preview, not a checkout. No customer revenue or independent usability result is claimed.
