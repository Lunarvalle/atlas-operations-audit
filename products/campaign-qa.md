# Bulk UTM Link Audit — Campaign Naming and URL Checks

Audit a batch of campaign links for missing or repeated UTM fields, inconsistent naming and sensitive query parameters.

## The job

Parametri mancanti, maiuscole incoerenti e URL duplicati frammentano la lettura delle campagne.

## Start with a synthetic example

1. Open the [input example](../examples/campaign-qa-input.json). These are invented test records, never customer data.
2. Read the [computed report](../examples/campaign-qa-report.json). It was generated by engine 1.0.0 with an explicit evaluation timestamp.
3. For a licensed installation, load the same fields into the browser app or call MCP tool `campaign_qa`.

## Required input

- Table a: `link_id, url`
- Table b: ``

CSV accepts comma, semicolon or tab separators. Use decimal points; keep currency explicit. Maximum 5,000 rows per table and 2 MB per file (MCP: 2 MB total request). Dates need a timezone. Missing or ambiguous data is rejected instead of silently guessed.

## Output and review

Structured report, row-level findings, priority actions, formula-safe CSV and an input/result fingerprint through MCP. The local browser edition also exports HTML. Inspect review flags before changing your operational system.

## Boundaries

Does not verify live analytics collection, cookies, consent or redirect behaviour.
