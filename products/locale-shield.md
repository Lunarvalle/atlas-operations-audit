# Locale Shield

Compare JSON dictionaries for missing/empty strings, simple placeholder and tag differences, and review signals.

## The job

Una stringa tradotta può perdere variabili, chiavi o tag necessari.

## Start with a synthetic example

1. Open the [input example](../examples/locale-shield-input.json). These are invented test records, never customer data.
2. Read the [computed report](../examples/locale-shield-report.json). It was generated by engine 1.0.0 with an explicit evaluation timestamp.
3. For a licensed installation, load the same fields into the browser app or call MCP tool `locale_shield`.

## Required input

- Table a: ``
- Table b: ``

CSV accepts comma, semicolon or tab separators. Use decimal points; keep currency explicit. Maximum 5,000 rows per table and 2 MB per file (MCP: 2 MB total request). Dates need a timezone. Missing or ambiguous data is rejected instead of silently guessed.

## Output and review

Structured report, row-level findings, priority actions, formula-safe CSV and an input/result fingerprint through MCP. The local browser edition also exports HTML. Inspect review flags before changing your operational system.

## Boundaries

Not translation quality review. Complex ICU messages need a specialist parser; no source-code unused-key analysis.

## Availability

The functional browser/CLI edition is built and internally tested. The hosted paid service is being qualified; this repository is a public technical preview, not a checkout. No customer revenue or independent usability result is claimed.
