# Payout Bridge

Match transaction batches to payout records by exact ID and currency; expose missing batches and arithmetic differences.

## The job

Commissioni, rimborsi e valute rendono difficile confrontare transazioni ed accrediti.

## Start with a synthetic example

1. Open the [input example](../examples/payout-bridge-input.json). These are invented test records, never customer data.
2. Read the [computed report](../examples/payout-bridge-report.json). It was generated by engine 1.0.0 with an explicit evaluation timestamp.
3. For a licensed installation, load the same fields into the browser app or call MCP tool `payout_bridge`.

## Required input

- Table a: `transaction_id, payout_id, currency, gross, fee, net`
- Table b: `payout_id, currency, amount`

CSV accepts comma, semicolon or tab separators. Use decimal points; keep currency explicit. Maximum 5,000 rows per table and 2 MB per file (MCP: 2 MB total request). Dates need a timezone. Missing or ambiguous data is rejected instead of silently guessed.

## Output and review

Structured report, row-level findings, priority actions, formula-safe CSV and an input/result fingerprint through MCP. The local browser edition also exports HTML. Inspect review flags before changing your operational system.

## Boundaries

No bank access, tax accounting or proof that money reached your bank.
