# Queue Focus

Build a review queue from explicit deadlines, assignment and last-update timestamps.

## The job

Le urgenze si disperdono fra priorità dichiarate, ticket senza owner e attività ferme.

## Start with a synthetic example

1. Open the [input example](../examples/queue-focus-input.json). These are invented test records, never customer data.
2. Read the [computed report](../examples/queue-focus-report.json). It was generated by engine 1.0.0 with an explicit evaluation timestamp.
3. For a licensed installation, load the same fields into the browser app or call MCP tool `queue_focus`.

CSV accepts comma, semicolon or tab separators. Use decimal points; keep currency explicit. Maximum 5,000 rows per table and 2 MB per file (MCP: 2 MB total request). Dates need a timezone. Missing or ambiguous data is rejected instead of silently guessed.

## Output and review

Structured report, row-level findings, priority actions, formula-safe CSV and an input/result fingerprint through MCP. The local browser edition also exports HTML. Inspect review flags before changing your operational system.

## Boundaries

Elapsed time only. Does not reproduce a helpdesk business-hours SLA engine.
