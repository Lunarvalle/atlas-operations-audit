# Stock Window

Turn stock, reserved units, inbound units, lead times and buying constraints into a reviewable reorder worksheet.

## The job

Scorte, prenotazioni e lotti minimi producono ordini urgenti o eccessivi.

## Start with a synthetic example

1. Open the [input example](../examples/stock-window-input.json). These are invented test records, never customer data.
2. Read the [computed report](../examples/stock-window-report.json). It was generated by engine 1.0.0 with an explicit evaluation timestamp.
3. For a licensed installation, load the same fields into the browser app or call MCP tool `stock_window`.

## Required input

- Table a: `sku, on_hand, reserved, on_order, units_sold, window_days, lead_days, safety_days, pack_size, moq, unit_cost, currency`
- Table b: ``

CSV accepts comma, semicolon or tab separators. Use decimal points; keep currency explicit. Maximum 5,000 rows per table and 2 MB per file (MCP: 2 MB total request). Dates need a timezone. Missing or ambiguous data is rejected instead of silently guessed.

## Output and review

Structured report, row-level findings, priority actions, formula-safe CSV and an input/result fingerprint through MCP. The local browser edition also exports HTML. Inspect review flags before changing your operational system.

## Boundaries

Historical averages, not demand forecasting. Incoming stock dates must be checked.
